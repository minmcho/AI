# Creating the Xcode Project

Since Xcode project files are complex binary/XML files that are best generated by Xcode itself, follow these steps to create a working project:

## Option 1: Create New Xcode Project (Recommended - 5 minutes)

### Step 1: Create New Project in Xcode

1. **Open Xcode**
2. **File → New → Project**
3. Choose **iOS** → **App**
4. Click **Next**

### Step 2: Configure Project

- **Product Name**: `HealthRashAI`
- **Team**: Select your team
- **Organization Identifier**: `com.healthrash` (or your own)
- **Bundle Identifier**: `com.healthrash.HealthRashAI`
- **Interface**: **SwiftUI**
- **Language**: **Swift**
- **Storage**: **None**
- **Uncheck**: Include Tests (we'll add later if needed)
- Click **Next**

### Step 3: Save Project

- Save to: `/Users/qsmlops04/Downloads/AI-claude-ai-health-rash-app-01N4kdPrhBNcMkTbtLQUmhoz/ios/`
- Click **Create**

### Step 4: Replace Default Files

Xcode will create some default files. Replace them with our files:

1. **Delete these default files** (right-click → Delete → Move to Trash):
   - `ContentView.swift` (we'll use ours)
   - `HealthRashAIApp.swift` (we'll use ours)
   - `Assets.xcassets` (keep this, we'll add icons later)
   - `Preview Content` folder (optional to keep)

2. **Add our source files** to the project:
   - Right-click on `HealthRashAI` folder in Xcode
   - Select **Add Files to "HealthRashAI"...**
   - Navigate to the `ios/HealthRashAI` folder
   - Select all `.swift` files
   - ✅ Check "Copy items if needed"
   - ✅ Check "Create groups"
   - ✅ Add to target: HealthRashAI
   - Click **Add**

### Step 5: Update Info.plist

1. Select your project in the navigator
2. Select the **HealthRashAI** target
3. Go to **Info** tab
4. Add the following **Custom iOS Target Properties**:

Click **+** and add each of these:

| Key | Type | Value |
|-----|------|-------|
| Privacy - Camera Usage Description | String | Health Rash AI needs camera access to take photos of skin rashes for medical analysis. All processing is done locally on your device. |
| Privacy - Microphone Usage Description | String | Health Rash AI needs microphone access to record your medical questions in your native language. Audio is processed locally and never sent to external servers. |
| Privacy - Speech Recognition Usage Description | String | Health Rash AI uses speech recognition to convert your spoken questions into text for AI analysis. All processing is done on-device to protect your privacy. |

### Step 6: Build and Run

1. Select a simulator (iPhone 15 Pro recommended)
2. Press **Cmd + R** or click the **Play** button
3. Grant permissions when prompted
4. Test the app!

## Troubleshooting

### Issue: "No such module 'SwiftUI'"
**Solution**: Make sure iOS Deployment Target is set to 16.0+
- Project Settings → General → Deployment Info → iOS 16.0

### Issue: Build errors in camera code
**Solution**:
1. Add Privacy descriptions to Info.plist
2. Run on a real device or iOS 16+ simulator

### Issue: Speech recognition not working
**Solution**:
1. Add Speech Recognition privacy description
2. Test on physical device (simulators have limited speech support)
